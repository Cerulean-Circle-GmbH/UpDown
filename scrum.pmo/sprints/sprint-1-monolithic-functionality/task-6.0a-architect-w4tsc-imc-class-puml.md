## Task Description
Create a PlantUML class diagram showing the **prod versions** of Web4TSComponent and IdealMinimalComponent, including their class hierarchies, relationships, and how they interplay (DelegationProxy pattern).

## Context
Web4TSComponent is the component lifecycle tool. IdealMinimalComponent is the reference "hello world" generated by Web4TSComponent. Understanding their class structure and interplay is the foundation for understanding ALL other components — every component follows the same pattern.

## Source Code to Read
- `components/Web4TSComponent/prod/` (resolve prod symlink to actual version)
- `components/IdealMinimalComponent/prod/` (resolve prod symlink to actual version)
- Focus on: layer2 (Default* classes), layer3 (interfaces), layer5 (CLI)

## Diagram Requirements
1. **Show all layer2 classes** with their key methods and properties
2. **Show inheritance:** DefaultWeb4TSComponent → UcpComponent, DefaultCLI → (base), DelegationProxy
3. **Show the DelegationProxy pattern:** How IdealMinimalComponent delegates to Web4TSComponent
4. **Show layer separation:** Group classes by layer (L2, L3, L4, L5)
5. **Show cross-component dependency:** IdealMinimalComponent → Web4TSComponent via DelegationProxy
6. **Label with Web4 Principles:** P6 (empty constructor), P16 (Object.verb naming), P19 (one file one type)
