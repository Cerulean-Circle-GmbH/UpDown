## Root Cause Diagnosis

### The Resolution Chain
```
Browser/Client → /scenario?ior=<value> → ScenarioRoute → provider → UcpStorage.scenarioLoad(uuid)
```

### UcpStorage.scenarioLoad() — ONLY accepts bare UUID
```typescript
// UcpStorage.ts:158
async scenarioLoad<T extends Model>(uuid: string): Promise<Scenario<T>> {
    const scenarioPath = this.scenarioIndexPathGet(uuid);
    // scenarioIndexPathGet builds: scenarios/index/{a}/{b}/{c}/{d}/{e}/{uuid}.scenario.json
    // This ONLY works with a clean 36-char UUID like "d90d3f43-5f26-4dc5-998c-e785b5b66ba2"
}
```

### 4 IOR Forms Seen in the Wild

| Form | Example | scenarioLoad() | Result |
|------|---------|----------------|--------|
| 1. Bare UUID | `d90d3f43-5f26-4dc5-998c-e785b5b66ba2` | ✅ Works | Scenario returned |
| 2. `ior:instance:` prefix | `ior:instance:d90d3f43-5f26-4dc5-998c-e785b5b66ba2` | ❌ Fails | Path contains "ior:instance:" → file not found |
| 3. `ior:scenario:` prefix | `ior:scenario:d90d3f43-5f26-4dc5-998c-e785b5b66ba2` | ❌ Fails | Same — prefix not stripped |
| 4. Symlink-derived path | `scenarios/type/Web4Requirement/0.3.20.6/d90d3f43...` | ❌ Fails | Path format completely different |

### Where Prefixed IORs Originate

- **Form 2 (`ior:instance:`):** Generated by UcpComponent's RelatedObjects registry and scenario `ior.uuid` fields when referenced cross-component
- **Form 3 (`ior:scenario:`):** Generated by IOR class `initRemote()` for scenario protocol references
- **Form 4 (symlink path):** Generated by `symlinkPaths[]` in scenario JSON (e.g., `"scenarios/type/Web4Requirement.type.scenario.json"`)

The ScenarioRoute's provider receives the raw `?ior=` query param and passes it directly to `scenarioLoad()` without normalization.

## Fix Specification

### Normalize IOR to bare UUID before scenarioLoad()

Add a normalization function that strips all known prefixes:

```typescript
/**
 * Normalize any IOR format to bare UUID for scenarioLoad()
 * Handles: bare UUID, ior:instance:uuid, ior:scenario:uuid, symlink path
 */
function normalizeIorToUuid(ior: string): string | null {
    if (!ior || ior.trim().length === 0) return null;
    
    const trimmed = ior.trim();
    
    // Form 1: Already a bare UUID (36 chars, 8-4-4-4-12 pattern)
    const uuidPattern = /^[0-9a-f]{8}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{12}$/i;
    if (uuidPattern.test(trimmed)) {
        return trimmed;
    }
    
    // Form 2+3: Strip ior: prefix variants
    // ior:instance:<uuid>, ior:scenario:<uuid>, ior:unit:<uuid>, ior:unit:uuid:<uuid>
    const iorPrefixMatch = trimmed.match(/^ior:(?:instance|scenario|unit)(?::uuid)?:([0-9a-f]{8}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{12})$/i);
    if (iorPrefixMatch) {
        return iorPrefixMatch[1];
    }
    
    // Form 4: Symlink-derived path — extract UUID from filename
    // "scenarios/type/.../d90d3f43-5f26-4dc5-998c-e785b5b66ba2.scenario.json"
    // or "scenarios/type/.../d90d3f43-5f26-4dc5-998c-e785b5b66ba2.type.scenario.json"
    const pathUuidMatch = trimmed.match(/([0-9a-f]{8}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{12})/i);
    if (pathUuidMatch) {
        return pathUuidMatch[1];
    }
    
    // No UUID found
    return null;
}
```

### Where to Apply

**Option A (recommended):** In `UcpStorage.scenarioLoad()` — normalize at the entry point:
```typescript
async scenarioLoad<T extends Model>(iorOrUuid: string): Promise<Scenario<T>> {
    const uuid = normalizeIorToUuid(iorOrUuid);
    if (!uuid) {
        throw new Error(`[UcpStorage] Invalid IOR/UUID: ${iorOrUuid}`);
    }
    const scenarioPath = this.scenarioIndexPathGet(uuid);
    // ... rest unchanged
}
```

**Option B (alternative):** In the ScenarioRoute provider, before calling scenarioLoad(). Less safe — every provider would need to normalize.

**Recommendation: Option A** — single point of normalization in UcpStorage. All callers benefit.

### Symlink-Path Resolution (Form 4)

For Form 4, if the path points to a symlink file (not UUID index), UcpStorage could also support direct file load:
```typescript
async scenarioLoad<T extends Model>(iorOrUuid: string): Promise<Scenario<T>> {
    const uuid = normalizeIorToUuid(iorOrUuid);
    
    if (uuid) {
        // Standard UUID-based index load
        return this.scenarioLoadByUuid(uuid);
    }
    
    // Fallback: try as direct file path (symlink-derived form)
    if (iorOrUuid.endsWith('.scenario.json') && existsSync(iorOrUuid)) {
        const content = await fs.readFile(iorOrUuid, 'utf8');
        return JSON.parse(content);
    }
    
    throw new Error(`[UcpStorage] Cannot resolve: ${iorOrUuid}`);
}
```
