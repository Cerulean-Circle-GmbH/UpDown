# Bug Report BR-014: Special Card Selection — No Visual Feedback + No Deselect

**Reporter:** McDonges (d1106ed8-8d8b-423f-87b6-f06b2d09a69e)
**Date:** 2026-05-18
**Status:** DONE

## Report
"i was in a game and it was countdown off. i had lots of time to see the special cards. i chose one, but there was no visual feedback if i chose it or played it. it should have been logged in as played card. but i should also be capable to deselect it and chose a different one. of course only as long as the countdown goes, but when countdown is off i have time to think and choose."

## Three Issues

### Issue 1: No visual feedback on special card selection
When clicking a special card, there's no visual indication that it was selected or played. The card should show a selected/active state (highlight, border, animation).

### Issue 2: No deselect / change selection
Once a special card is clicked, it's played immediately with no way to change your mind. Should be a two-step process:
1. Click to SELECT (visual highlight, not yet played)
2. Click again to CONFIRM (or click a different card to switch)
3. Only CONFIRMED selection is sent to server as PLAY_SPECIAL

### Issue 3: Countdown interaction
- Countdown OFF: unlimited time to select/deselect/change special card
- Countdown ON: selection must be confirmed before countdown expires
- If countdown expires with a selected (but unconfirmed) card: auto-confirm it? Or deselect?

## Chat Log
Special card plays should appear in the game chat log as played actions.

## Architect Spec — 2026-05-18

### Current State

MultiplayerUI.ts lines 580-586: clicking a special card button immediately calls `client.playSpecial(cardId)` and disables the button. No selection state, no visual feedback, no deselect, no target picker.

4 of 11 cards have `targetType: 'other'` (Sacrifice, Swap, Freeze, Steal) — currently sent without `targetPlayerId`, so the server ignores the target effect (checked in SpecialCards.ts: `if (played.targetPlayerId)` guards).

### Flow Spec: Two-Step Select → Confirm

```
STATE MACHINE (client-side, per round):

  IDLE → [click card] → SELECTED
  SELECTED → [click same card] → CONFIRMED → PLAY_SPECIAL sent
  SELECTED → [click different card] → SELECTED (switched)
  SELECTED → [click "×" or card area background] → IDLE (deselected)
  SELECTED(targetType='other') → [click card] → TARGET_PICKER shown
  TARGET_PICKER → [click player name] → CONFIRMED → PLAY_SPECIAL sent with targetPlayerId
  TARGET_PICKER → [click "×" or outside] → SELECTED (back, no target)
  
  ANY → [countdown expires] → selectedCard auto-confirmed (send PLAY_SPECIAL)
  ANY → [guess played (up/down/equal)] → selectedCard auto-confirmed if SELECTED
  CONFIRMED → card removed from inventory, button greyed out
```

### Visual States

| State | Card Button Appearance |
|-------|----------------------|
| IDLE | Default — emoji + name, normal border |
| SELECTED | Glowing border (gold), slight scale(1.05), pulsing shadow |
| CONFIRMED | Green check overlay ✅, disabled, opacity 0.6 |
| OTHER cards when one SELECTED | Slightly dimmed but clickable (allows switch) |

### Target Picker (for targetType='other')

When selecting Sacrifice/Swap/Freeze/Steal:
1. First click → card enters SELECTED state (gold border)
2. A target picker overlay appears BELOW the card area showing alive players:
   ```
   ┌──────────────────────────────┐
   │ 🎯 Choose target for Freeze: │
   │  [Alice]  [Bob]  [Charlie]   │
   │           [Cancel]           │
   └──────────────────────────────┘
   ```
3. Click player → CONFIRMED + PLAY_SPECIAL sent with `targetPlayerId`
4. Click Cancel → back to IDLE

For `targetType: 'self'` or `'all'`: no target picker. Second click confirms directly.

### Countdown Interaction

| Scenario | Behavior |
|----------|----------|
| Countdown ON, card SELECTED, timer expires | Auto-confirm: send PLAY_SPECIAL (with no target if targetType='other' — server handles gracefully) |
| Countdown ON, card IDLE, timer expires | No special card played (current behavior) |
| Countdown OFF, card SELECTED | Stays SELECTED indefinitely until player confirms or deselects |
| Countdown OFF, guess played while card SELECTED | Auto-confirm special card, then send guess |
| Round resolves, card was SELECTED but not confirmed | Deselect — card returns to inventory |

      }

    } else {

        this.showTargetPicker(cardId);
      }
    }
  });

private confirmSpecialCard(cardId: string, targetPlayerId?: string): void {
  this.client.playSpecial(cardId, targetPlayerId);
  this.inventory = this.inventory.filter(id => id !== cardId);
  this.selectedSpecialCard = null;
  this.renderGame(); // Re-render without the played card
}

private updateSpecialCardVisuals(): void {
  document.querySelectorAll('.btn-special').forEach(btn => {
    const id = (btn as HTMLElement).dataset.card;
    btn.classList.toggle('btn-special-selected', id === this.selectedSpecialCard);
    btn.classList.toggle('btn-special-dimmed', 
      this.selectedSpecialCard !== null && id !== this.selectedSpecialCard);
  });
}
