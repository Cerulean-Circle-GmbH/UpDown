# Bug Report BR-003: Secret Code Not Propagating + Profile Display Issues

**Reporter:** Anonymous (via browser bug report)
**Date:** 2026-05-15
**Status:** DONE

## Report
"i changed my secret number, but it did not propagate to the user profile and somehow changed back. i can see the devices in my profile, but i also need to see the ip address of them. i can see the token in the profile, but its shortened. it should be complete."

## Three Issues

### Issue 1: Secret code change not propagating to /profile
User changes code in lobby editor → /profile still shows old code. The /profile page is server-rendered on load — if the page was already open, it won't reflect changes made in the lobby editor. May need page refresh or live update.

### Issue 2: Device IP address and hostname not shown in /profile
Devices list shows device info but missing IP address and hostname. IP is stored in DeviceInfo (server.ts) — just not rendered in the /profile HTML. Also show hostname if available (may need reverse DNS or OS hostname from client).

### Issue 3: Token shown shortened in /profile
Token (UUID) is truncated/shortened in display. Should show the complete token.

## Fix (expert — after T29-31 DRY queue)
1. /profile: ensure secret code renders current value (force refresh or read from saved profile)
2. /profile device list: add IP address column
3. /profile: show full token, not truncated

## Acceptance Criteria
- [ ] Change code in lobby editor → /profile shows updated code on refresh
- [ ] Device list on /profile shows IP address and hostname (if available) per device
- [ ] Token shown in full (not shortened) on /profile
